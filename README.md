# Постановка задачи на разработку: Сортировка фильмов и сериалов по рейтингу

## Описание и цель проекта
Разработать системные требования и контракты API для онлайн-кинотеатра **Otium**, чтобы пользователи могли сортировать фильмы и сериалы в разделе «Библиотека» по рейтингу зрителей (`rating`) и рейтингу кинокритиков (`criticsRating`).
**Стек и инструменты:** UML (Sequence Diagram), Use Case, REST API, JSON, HTTP GET, PDF, Markdown.

## Проработанные артефакты
* **UML Sequence Diagram** — схема межсервисного взаимодействия (`UI: Otium` -> `Web Server` -> параллельные запросы к `Films Server` и `Series Server`).
* **Спецификация REST API** — доработка методов `/films/list`, `/films`, `/series/list`, `/series`, `/content/list` и `/content/details` (добавление поля `criticsRating` и query-параметров `sortBy`, `direction`).
* **Обработка краевых случаев** — логика работы при отсутствии оценки критиков (`criticsRating = 0` и вывод в конце списка).

## Выводы и результаты проекта
* Спроектирована архитектура параллельного опроса микросервисов фильмов и сериалов для минимизации времени ответа пользователю при фильтрации и сортировке.
* Исключены ошибки при работе с контентом без оценок критиков за счёт явного задания значения по умолчанию и правил сортировки граничных значений.
* Подготовлена полная спецификация с примерами JSON-ответов, готовая для передачи в разработку и тестирование.
