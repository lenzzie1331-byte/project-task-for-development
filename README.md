# Постановка задачи на разработку: Сортировка фильмов и сериалов по рейтингу

## Цель и бизнес-контекст
Дать пользователям онлайн-кинотеатра **Otium** возможность сортировать фильмы и сериалы в разделе «Библиотека» не только по рейтингу зрителей (`rating`), но и по рейтингу кинокритиков (`criticsRating`) в прямом и обратном порядке.

## Проработанные артефакты и логика решения
В рамках задачи спроектировано межсервисное взаимодействие и описаны требования к доработке трех микросервисов:

* **UML Sequence Diagram** — визуализация процесса обработки запроса от интерфейса (`UI: Otium`) через `Web Server` с параллельными запросами (`par`) к `Films Server` и `Series Server`, а также последующей фильтрацией и сортировкой (`opt`).
* **Доработка Films Server API и Series Server API** — добавление опционального числового поля `criticsRating` (диапазон `0–10`) в ответы методов получения списков (`/films/list`, `/series/list`) и карточек контента (`/films`, `/series`).
* **Доработка Web Server API** — добавление параметров сортировки `sortBy` (`rating` / `criticsRating`) и направления `direction` (`asc` / `desc`) в запросы `/content/list` и `/content/details`, а также проброс поля `criticsRating` в ответы.
* **Обработка краевых случаев и ошибок** — описана логика работы при отсутствии оценки критиков (присвоение значения `0` по умолчанию и вывод такого контента в конце отсортированного списка).
